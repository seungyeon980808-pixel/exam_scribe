# 수능양식 ai

기준 문서는 `200909과학탐구영역물리II문제.hwp`이다. 원본은 A3 세로 4쪽,
신문형 2단, 20문항, 그림 21개 구조다. 첫 면과 4쪽 비교본은 원본의 용지·여백·
마스터 페이지를 보존한다.

## 실제 원본 기반 물감

아래 문항 물감은 학교 시험지용 기존 물감을 복제하지 않는다. 기준 HWPX의 실제
문항 범위에서 문단 모양, 신명 계열 글꼴, 그림 자리와 감싸기, `<보 기>` 3×3 표,
탭 정렬 선지를 직접 추출한 뒤 내용만 이름표 슬롯으로 바꾼다.

- `\수능AI실제직접형\`: 문항 번호, 발문, 질문, 선지 1~5
- `\수능AI실제합답형\`: 문항 번호, 발문, 질문, 보기 ㄱ~ㄷ, 선지 1~5
- `\수능AI실제인물합답형\`: 문항 번호, 발문, 질문, 발언 1~3, 선지 1~5
- `\수능AI실제실험형\`: 문항 번호, 실험 과정, 질문, 발언 1~3, 선지 1~5
- `\수능AI실제비교선지형\`: 문항 번호, 발문, 질문, 표 머리, 선지 1~5
- `\수능AI실제자료표형\`: 문항 번호, 자료표, 발문, 질문, 표 머리, 선지 1~5

그림은 원본과 같은 크기의 흰 이미지로 들어가므로 자리와 줄 흐름은 유지된다.
최종 그림 교체는 한글에서 해당 그림 개체의 그림 바꾸기를 이용한다.

## 등록과 재생성

생성기는 각 HWP 조각을 HwpPalette의 정식 등록 함수
`add_template_from_capture`/`replace_template_fragment`에 넘긴다. 라이브러리 JSON이나
팔레트 파일에 조각 경로를 임의로 꽂지 않는다.

```powershell
python tools/build_csat_ai_palette.py data/csat_ai_analysis/reference.hwpx
python -m hwp_palette.cli --markdown-file examples/수능양식_ai_테스트.md --output output/수능양식_ai_테스트.hwp
```
