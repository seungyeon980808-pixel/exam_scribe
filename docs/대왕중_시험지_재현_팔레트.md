# 대왕중 시험지 재현 팔레트

이 팔레트는 `대왕중 시험문제 복원.hwpx`의 수치를 추정해서 비슷하게 만든 것이
아니다. 기준 HWPX의 쪽 설정과 문항 표를 직접 복제한 뒤, 그림 개체만 제거하고
내용 위치를 HwpPalette 이름표로 바꾼 것이다.

## 설치

```powershell
python -X utf8 tools\build_reference_exam_palette.py "기준문서.hwpx"
```

설치되는 팔레트 탭은 `대왕중 시험지 재현`이다. 핵심 물감은 다음 두 개다.

- `대왕중2단틀`: A4 10mm 여백, 2단 4mm, 중앙 구분선, 쪽 테두리,
  시험 정보표와 자동 쪽 번호 꼬리말을 포함한 전체 원안지 양식
- `대왕중그림합답`: 그림 자리는 비워 둔 9행×16열 합답형 문항
- `대왕중일반선택`: 그림 없는 일반 5지선다형
- `대왕중합답0그림`: 그림 없는 ㄱ·ㄴ·ㄷ 합답형
- `대왕중합답2그림`: 좌우 그림 두 칸을 비운 ㄱ·ㄴ·ㄷ 합답형
- `대왕중배점현황`: 첫 페이지 배점 현황 상자

문항 물감의 이름표 순서는 다음과 같다.

```text
번호, 발문, 질문, 배점,
보기1, 보기2, 보기3,
선지1, 선지2, 선지3, 선지4, 선지5
```

AI가 원고를 만들 때에는 먼저 양식을 한 번 호출하고 문항 물감을 반복 호출한다.
실제 문법은 `examples/대왕중_참고본_재현.md`를 그대로 참고하면 된다.
전체 유형과 그림 칸을 `-`로 비우는 문법은
`examples/대왕중_AI_문항유형_검증.md`에 들어 있다.

## 보존되는 조판 값

- 전체 양식: A4, 사방 10mm, 2단, 단 사이 4mm
- 문항 표: 92.3×123.47mm, 9행×16열, 실제 셀 30개
- 빈 그림 영역: 50.75mm
- 글꼴: 한컴산뜻돋움
- 문항 번호: 12pt, 굵게, 장평 95%, 자간 33%
- 발문: 11pt, 장평 95%, 자간 -15%, 줄간격 145%
- 질문·보기: 11pt, 장평 95%, 자간 -5%, 줄간격 155%
- 선택지: 11.48pt, 장평 95%, 셀별 자간 -5/-5/-47/-47/-41%
- 보기 내용 셀: 좌우 2mm, 위 1.5mm, 아래 3mm

빈 그림 셀은 원본 그림 높이 46.25mm와 위아래 여백을 합친 50.75mm를 유지한다.
이 높이를 줄이면 두 번째 문항이 오른쪽 단으로 넘어가지 않고 왼쪽 아래에 쌓인다.

## 검증 결과

기준 문서와 생성 PDF를 같은 한글 렌더러에서 96dpi로 출력해 두 그림 영역만
제외하고 비교했다. 794×1122 페이지에서 경계 안티앨리어싱 1픽셀을 제외한 모든
픽셀이 일치했다. 구조 검증과 전체 프로젝트 테스트도 자동화되어 있다.
